# Engine flows (A242)

One n8n flow per world (DESIGN.md §5). Each file imports into the Kalpa n8n engine; each has a test that runs its Code nodes with fake inputs.

| World | Flow | Test |
|---|---|---|
| b1 BotBhai | `b1-frontdesk-watchdog.json` (built by `b1_watchdog_build.py`): every 15 min, reads handed-over chats (status human), staff replies and business names from BotBhai Supabase (GET only, no message text), tells Akhil privately on Telegram when a customer waited 20+ min for a person, and when the WhatsApp 24 h window is closing or closed. Phones masked, alerts deduped, max 10 lines | `node test_b1_frontdesk_watchdog.js` |
| b2 App studio | `b2-review-watcher.json` (built by `b2_review_watcher_build.py`): daily 09:40 IST, reads `02-jobcard/store/reviews.json` (app, id, rating, text; no names), no model: keyword topics (crash, login, notifications, data, slow, payment) in 5 languages, repeat-problem alerts, ★1–2 reviews worst first, injected text flagged and not shown, one private Telegram digest to Akhil | `node test_b2_review_watcher.js` |
| b3 Exam Kits | `b3-exam-alerts.json` (built by `b3_exam_alerts_build.py`): daily 07:40 IST, reads `03-kits/engine/dist/exam-dates.json` (made by `03-kits/engine/export_dates.py` from the kit YAML key_dates), no model: drafts alerts for new/changed CONFIRMED dates from official sites (.gov.in/.nic.in/.ac.in/.edu.in) and 7-day/1-day reminders, flags past dates, clashes, unofficial or missing sources; drafts (English + Telugu when the data has it) go only to Akhil's private Telegram, never to students | `node test_b3_exam_alerts.js` |
| b3 Exam Kits | `b3-doubt-bot.json` (built by `b3_doubt_bot_build.py`): webhook POST `{user, text}` with a header key (Akhil sets), replies in the student's own language (English, Telugu, Hindi, Tenglish, Hinglish) with a free OpenRouter model; leak/cheat and injection requests get fixed refusals without a model call; 20 doubts per user and 300 per day; answers checked (script, no links/contacts, length) else a safe reply; doubt text never stored | `node test_b3_doubt_bot.js` |
| b4 Tab Lifeboat | `b4-review-replies.json`: daily 10:20 IST, reads `04-extensions/store/reviews.json` (id, rating, text; no names), drafts up to 3 replies with a free OpenRouter model, checks them, sends drafts to Akhil's private Telegram | `node test_b4_review_replies.js` |
| b5 Deals | `b5-deal-checker.json` (built by `b5_deal_checker_build.py`): daily 08:20 IST, reads `05-deals/site/src/bot/deals.json` (hand-filled, never scraped), no model: checks today's product deals (price under 24 h old, https store link, no money products), runs the ASCI #ad check on each post, compares price with the team's own 90-day log and yesterday's price, sends a ready/fix digest only to Akhil's private Telegram; never posts to the channel | `node test_b5_deal_checker.js` |
| HQ | `hq-morning-brief.json` (built by `hq_morning_brief_build.py`): daily 07:00 IST, reads `00-hq/ROADMAP.md` + `00-hq/tasks/*.json` (10 GETs, public repo), no model: Akhil's open CEO items (longest waiting first, ⏳ after 7 days), what the build team does next (in progress, to start, blocked), free-agent row counts, and problems (bad task JSON, duplicate ids, two lanes on one item); one private Telegram message. The 21:00 IST evening brief (`00-hq/tools/daily_brief.py`) keeps alerts + what got done | `node test_hq_morning_brief.js` |
Import: n8n → Workflows → Import from file. b1: set the Supabase URL in its Settings node and a Custom Auth credential "BotBhai Supabase (read only)" (headers apikey + Authorization; a read-only key, never the service key in chat) yourself. Set the two credentials (OpenRouter header `Authorization: Bearer …`, Kalpa Telegram) yourself in n8n. Files ship `active: false`; nothing has a public URL. The b3 doubt bot is the only one with a webhook: it needs its own header key credential and Akhil's "go" before it is switched on.
