| Build | Goal | Minimal code (copy‑paste into a Colab cell) |

| **3️⃣ Mini‑todo list (Google Sheet backend)** | Store, list, and delete tasks via Claude. | ```python\nimport gspread\nfrom google.oauth2.service_account import Credentials\n\n# 1️⃣ Connect to sheet (service‑account JSON uploaded to Colab)\nscope = [\"https://www.googleapis.com/auth/spreadsheets\"]\ncreds = Credentials.from_service_account_file('service_account.json', scopes=scope)\ngc = gspread.authorize(creds)\nsheet = gc.open('Claude_Todo').sheet1\n\n# 2️⃣ Prompt Claude to generate a JSON command (add/list/delete)\nuser_input = \"Add task: చదవండి GATE notes\"\nprompt = f\"You are a task manager. Respond with JSON: {{\\\"action\\\": \\\"add\\\", \\\"task\\\": \\\"{user_input}\\\"}}\"\nresp = client.completions.create(model=\"claude-3-sonnet-20240229\", max_tokens=30, temperature=0, prompt=prompt)\ncmd = eval(resp.completion.strip())\n\n# 3️⃣ Execute command on sheet\nif cmd['action'] == 'add':\n    sheet.append_row([cmd['task']])\nelif cmd['action'] == 'list':\n    print(sheet.get_all_values())\nelif cmd['action'] == 'delete':\n    # simple delete by row number (example only)\n    sheet.delete_rows(int(cmd['task']))\n``` |
