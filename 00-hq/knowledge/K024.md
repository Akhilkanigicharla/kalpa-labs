## 5. Rollback Procedures (If Broken)

If a critical check fails after go-live, execute the matching isolation step immediately:

1. **HQ Website / Static Pages (Netlify):**
   * Revert to the previous deploy hash in the Netlify control panel.
   * Run `git revert HEAD` on main branch and push to restore stable build.

2. **BotBhai WhatsApp Webhook (O1):**
   * Disable the n8n WhatsApp trigger workflow.
   * Redirect incoming WhatsApp messages to an automated "Maintenance/Offline" template response.

3. **Deals Bot (O3):**
   * Pause the Telegram poster schedule in n8n.
   * Revoke or pause the Telegram bot token temporarily in `.env`.

4. **Digital Goods / Workshop Pages (O4 & O5):**
   * Flip page flag to `maintenance: true` to replace the UPI payment display with an email capture form.
   * Stop automated delivery webhooks to prevent misrouted files.

5. **Database / API Layers:**
   * Fallback to read-only mode for Supabase endpoints.
   * Revert backend n8n workflows to the last exported JSON snapshot in repo.
