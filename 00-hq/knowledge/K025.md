## 📂 What the script covers
| Scenario | What the user wants | Bot must do |
|----------|--------------------|-------------|
| 1️⃣ Booking | New appointment | Collect **service → date → time → name**, confirm, suggest nearest free slot if chosen slot is taken. |
| 2️⃣ Reschedule | Change an existing slot | Identify original booking (by name & date), offer next‑available times, confirm new slot. |
| 3️⃣ Angry Customer | Complaint / bot‑mistake | Acknowledge frustration, apologize, **escalate to human** (owner‑hand‑over). |

| 5️⃣ Timing Inquiry | “When can I get a haircut?” | List next 3‑5 available slots for the requested service. |
