### Top 5 Missing Patterns (Fix Order)

1. **Pattern 7: Debouncing (`DSH-01`)**
   - *Fix plan*: Add a 300 ms debounce timer to the `#q` input search listener in `dashboard.html` so `renderLeads()` is not re-run on every keystroke.
   - *Code fix*:
     ```js
     var searchTimer;
     $("q").addEventListener("input", function (e) {
       clearTimeout(searchTimer);
       searchTimer = setTimeout(function () { S.q = e.target.value; renderLeads(); }, 300);
     });
     ```

2. **Pattern 9: Smart Form Validation (`DSH-02`)**
   - *Fix plan*: Validate the dashboard key field on blur and show plain-language feedback before submit.
   - *Code fix*:
     ```js
     $("key").addEventListener("blur", function () {
       var v = $("key").value.trim();
       if (v && !/^[a-f0-9-]{36}$/i.test(v)) {
         $("signin-err").textContent = "Key should be 36 characters. Check your setup text.";
       }
     });
     ```

3. **Pattern 1: Optimistic UI Updates (`INB-01`)**
   - *Fix plan*: Append the outgoing text bubble immediately to the message thread with a pending visual state; revert and notify on network request fail.
   - *Code fix*:
     ```js
     function sendMsg(text) {
       var tempMsg = { text: text, sender: "staff", pending: true };
       renderMsg(tempMsg);
       apiSend(text).catch(function () { tempMsg.failed = true; toast("Couldn't send. Retry?"); });
     }
     ```

4. **Pattern 19: Destructive Action Protection (`DSH-03`)**
   - *Fix plan*: Require explicit tap confirmation when clearing local authorization keys or resetting session data.
   - *Code fix*:
     ```js
     function clearSession() {
       if (confirm("Sign out of this phone? You will need your key to open it again.")) {
         store.set(""); location.reload();
       }
     }
     ```

5. **Pattern 12: Remember Filter State per User (Enhancement for Pattern 12)**
   - *Fix plan*: Save the selected lead filter chip (`S.filter`) to `localStorage` so user context persists across reloads.
   - *Code fix*:
     ```js
     var savedFilter = localStorage.getItem("botbhai.lead.filter");
     if (savedFilter) S.filter = savedFilter;
     // inside chip click: localStorage.setItem("botbhai.lead.filter", S.filter);
     ```
