## Top 5 Missing Patterns (Fix Order)

### 1. Graceful error recovery (Pattern 20)
Wrap the app root in an error boundary that shows a retry button and keeps local job data intact when network or rendering errors occur.

```tsx
<ErrorBoundary fallback={({ reset }) => (
  <View style={{ padding: 16, backgroundColor: k.panel }}>
    <Text style={{ fontFamily: bodyFonts(language).bold }}>Couldn't save. Your work is safe.</Text>
    <Button title="Retry" onPress={reset} />
  </View>
)}>
  <Tabs />
</ErrorBoundary>
```

### 2. Loading and empty states (Pattern 5)
Display a grey skeletal layout while fetching job cards, and render an explicit call to action when no job cards exist.

```tsx
if (isLoading) return <SkeletonLoader count={3} />;
if (jobs.length === 0) return <EmptyState title="No jobs yet" actionText="Add first job" onPress={onAdd} />;
```

### 3. Optimistic UI updates (Pattern 1)
Update the job status immediately on tap in the local React state, rolling back only if the API persistence call rejects.

```tsx
const toggleJob = (id: string) => {
  setJobs(prev => prev.map(j => j.id === id ? { ...j, done: !j.done } : j));
  api.updateJob(id).catch(() => setJobs(previousJobs));
};
