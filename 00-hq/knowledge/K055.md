### Top 5 Missing Patterns (Fix Order)

1. **Pattern 5: Loading and empty states**  
   Add empty state structures inside lists like `<ol id="needlist">` showing a helpful message ("No pending tasks") alongside a direct primary call to action.

2. **Pattern 12: Advanced filtering**  
   Populate `#qfilters` and `#hostfilter` with removable filter chip elements (`.kx-pill`) that persist state per user session.

3. **Pattern 7: Debouncing**  
   Attach a 300 ms debounce listener to the `#q` search input field to restrict query calls during live typing.

4. **Pattern 20: Graceful error recovery**  
   Render explicit error feedback cards with an inline `Retry` button inside data-bound sections when network data fetches fail.

5. **Pattern 2: Skeleton loaders**  
   Replace static dash placeholders (`—`) with CSS pulse-animated skeleton shapes matching the card typography layout.
