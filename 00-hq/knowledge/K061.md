Here are 12 free public APIs selected from the public-apis collection for Kalpa Labs:

1. **Nager.Date**
   * **What it gives:** Public holiday dates by country code and year.
   * **Kalpa usage:** Exam Kits (b3) uses it to cross-check exam dates against public and regional holidays to send schedule alerts.
   * **Auth needed:** None
   * **Free limit:** UNVERIFIED

2. **Zippopotam.us**
   * **What it gives:** Postal code lookups (including India IN pincodes) returning state, district, and location names.
   * **Kalpa usage:** BotBhai (b1) uses it to auto-fill salon and gym addresses during client onboarding.
   * **Auth needed:** None
   * **Free limit:** UNVERIFIED

3. **Open-Meteo**
   * **What it gives:** Historical, real-time, and forecast weather data by coordinates without API keys.
   * **Kalpa usage:** Telugu Deals & calculators (b5) uses it to show local weather alerts alongside daily regional utility/agro calculators.
   * **Auth needed:** None
   * **Free limit:** UNVERIFIED

4. **ExchangeRate-API**
   * **What it gives:** Daily currency exchange rates against major currencies including INR.
   * **Kalpa usage:** Telugu Deals & calculators (b5) uses it to power currency and NRIs remittance savings calculators.
   * **Auth needed:** Key
   * **Free limit:** UNVERIFIED

5. **Yahoo Finance API (yfinance wrapper)**
   * **What it gives:** Historical stock market OHLCV data, equities, and indices updates.
   * **Kalpa usage:** Trading Lab research (b7) uses it for offline data retrieval to build backtests.
   * **Auth needed:** None
   * **Free limit:** UNVERIFIED

6. **Frankfurter**
   * **What it gives:** Open-source currency rates published by the European Central Bank.
   * **Kalpa usage:** Trading Lab research (b7) uses it for macroeconomic FOREX backtesting models.
   * **Auth needed:** None
   * **Free limit:** UNVERIFIED

7. **Sunrise-Sunset API**
   * **What it gives:** Sunrise, sunset, and twilight timings for any latitude and longitude.
   * **Kalpa usage:** Telugu Deals & calculators (b5) uses it for panchangam and local timing calculation tools.
   * **Auth needed:** None
   * **Free limit:** UNVERIFIED

8. **Rest Countries**
   * **What it gives:** Information on countries including call codes, currencies, languages, and regional flags.
   * **Kalpa usage:** Exam Kits (b3) uses it to filter international study exam eligibility requirements.
   * **Auth needed:** None
   * **Free limit:** UNVERIFIED

9. **Open Food Facts**
   * **What it gives:** Ingredients, nutritional labels, and product details for consumer packaged goods.
   * **Kalpa usage:** BotBhai (b1) uses it to pull nutritional data for gym client meal tracker widgets.
   * **Auth needed:** None
   * **Free limit:** UNVERIFIED

10. **GitHub REST API**
    * **What it gives:** Public repository metadata, releases, and commit statistics.
    * **Kalpa usage:** Trading Lab research (b7) uses it to monitor open-source quantitative finance repo updates.
    * **Auth needed:** None (Key optional for higher rate limits)
    * **Free limit:** UNVERIFIED

11. **Wikimedia REST API**
    * **What it gives:** Wikipedia page summaries, educational topic overviews, and media links.
    * **Kalpa usage:** Exam Kits (b3) uses it to enrich quick revision flashcards with topic summaries.
    * **Auth needed:** None
    * **Free limit:** UNVERIFIED

12. **APIs.guru**
    * **What it gives:** OpenAPI specifications directory for public REST APIs.

    * **Auth needed:** None
