### Section 1: Error Tracking

1. **Frontend Error Collection**
   Add a global handler in `app.js` catching `window.onerror` and `window.addEventListener('unhandledrejection')`. Fire a background `fetch` to `/api/chat?action=log_error` with payload data formatted as a single log line.

2. **Payload Fields (Keep vs Drop)**
   * **Keep**: `error_message` (truncated to 200 chars), `source_file` (filename only), `line_number`, `col_number`, `stack_trace` (first 2 frames).
   * **Drop**: Visitor IP address, user-agent string, input field values, user phone number, name, email, query string parameters.
