1. **Free plan automatic backups:** The Supabase Free plan does not include daily automatic backups, and free project backups cannot be downloaded from the dashboard (Source: https://supabase.com/docs/guides/platform/backups).

2. **Supabase CLI dump command:** You take a logical schema and data dump using `supabase db dump --db-url "postgres://..."` via the Supabase CLI (Source: https://supabase.com/docs/guides/database/backup-restore#logical-backups).

3. **Connection string details:** The CLI dump requires the Direct Postgres connection string on port 5432 (or the session pooler on port 5432). Because standard GitHub Actions runners only support IPv4, you must use the Supabase IPv4 connection string or direct connection host provided in project settings (Source: https://supabase.com/docs/guides/database/connecting-to-postgres).

4. **Direct pg_dump alternative:** If using standard `pg_dump`, run `pg_dump -h db.[ref].supabase.co -U postgres -d postgres -F p -f dump.sql` using the direct connection string (Source: https://supabase.com/docs/guides/database/backup-restore#using-pg_dump-and-pg_restore).

5. **Restoring to Postgres 16:** Restore the output text file into a target Postgres 16 database using `psql -h localhost -U postgres -d target_db -f dump.sql` (Source: https://supabase.com/docs/guides/database/backup-restore#restoring-a-logical-backup).
