Here is the comparison between `npm audit --omit=dev` and Google's `osv-scanner` for GitHub Actions steps on directories containing `package-lock.json`.

1. **Licence of the Tool**
   * **npm audit:** Artistic License 2.0 (bundled as part of the `npm` CLI project).  
     *Official doc URL:* https://github.com/npm/cli/blob/main/LICENSE
   * **osv-scanner:** Apache License 2.0.  
     *Official doc URL:* https://github.com/google/osv-scanner/blob/main/LICENSE

2. **Install Line in GitHub Actions**
   * **npm audit:** Built into Node.js (no extra installation step required if `actions/setup-node` is used).  
     *Official doc URL:* https://docs.npmjs.com/cli/v10/commands/npm-audit
   * **osv-scanner:** `go install github.com/google/osv-scanner/cmd/osv-scanner@v1.9.2` (or via official GitHub Action `google/osv-scanner-action`).  
     *Official doc URL:* https://google.github.io/osv-scanner/installation/

3. **Exit Codes for High/Critical Vulnerabilities**
   * **npm audit:** `--audit-level=high` causes `npm audit` to exit with non-zero (exit code 1) when vulnerabilities at or above `high` severity are found.  
     *Official doc URL:* https://docs.npmjs.com/cli/v10/commands/npm-audit#audit-level
   * **osv-scanner:** Exits with code 1 by default when any vulnerability is found, or code 0 if none. `--fail-on` flag can be set to threshold level (e.g., `--fail-on=high`).  
     *Official doc URL:* https://google.github.io/osv-scanner/usage/#failing-on-vulnerabilities

4. **How to Ignore One Advisory with a Reason**
   * **npm audit:** Standard `npm audit` does not natively support ignoring single advisory IDs via command flags without third-party helpers (like `npm-audit-resolver`). Alternatively, audit exceptions are handled by overriding specific vulnerable dependency versions in `package.json` `overrides`.  
     *Official doc URL:* https://docs.npmjs.com/cli/v10/configuring-npm/package-json#overrides
   * **osv-scanner:** Create an `osv-scanner.toml` configuration file in the project folder detailing `[[ignores]]` with `id` and `reason` fields, or pass `--config=path/to/osv-scanner.toml`.  
     *Official doc URL:* https://google.github.io/osv-scanner/configuration/

5. **Network Dependency**
   * **npm audit:** Requires an active network connection to query the npm registry advisory database during execution.  
     *Official doc URL:* https://docs.npmjs.com/cli/v10/commands/npm-audit#description
   * **osv-scanner:** Requires network access to query the OSV API online database (https://api.osv.dev), though it can run offline if local database dumps are pre-downloaded and specified.  
     *Official doc URL:* https://google.github.io/osv-scanner/architecture/
