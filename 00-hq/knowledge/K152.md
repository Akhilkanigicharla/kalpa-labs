1. **What Langfuse is**: Langfuse is an open-source LLM engineering platform built around an MIT-licensed core to track model usage and performance metrics.

2. **Where your data lives**: Your telemetry remains inside your own Langfuse account. Specific cloud hosting regions and server locations are UNVERIFIED.

3. **Your API keys**: You generate two project API keys (`LANGFUSE_PUBLIC_KEY` and `LANGFUSE_SECRET_KEY`) inside your account settings and share them only via your environment or secure secret store.

4. **What our audit script reads**: Our script (`langfuse_pull.py`) fetches basic operational numbers: model names, token counts, cache hits, request status, and total costs reported by your instance. It excludes prompt and response text by omitting the `io` field group. Langfuse platform pricing plans remain UNVERIFIED cost data.

5. **Data privacy**: We pull technical usage logs only. No end-user credentials, email addresses, or message content are extracted or retained.

6. **Revoking access**: You can revoke our access instantly by deleting or disabling the API keys in your Langfuse project dashboard.

7. **Audit output**: Extracted metrics are saved locally to a `usage.csv` file to calculate cost reduction opportunities.

8. **Contact support**: For assistance with key setup, script verification, or data deletion requests, contact the Kalpa Labs FinOps team.
