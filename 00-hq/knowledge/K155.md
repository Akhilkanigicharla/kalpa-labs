A224 prep: SEBI retail algo static-IP rule and free fixed-IP options

1. Static IP registration
The trader gives the broker one fixed IP address. The broker registers it and blocks algo orders from any other IP.
Circular: unverified. Source: sebi.gov.in or nseindia.com.

2. Algo ID
The exchange or broker issues one Algo ID for each strategy. Every order must carry that ID.
Circular: unverified. Source: sebi.gov.in or nseindia.com.

3. 2FA
The trader must use two-factor authentication to switch on algo trading and to place orders through the API.
Circular: unverified. Source: sebi.gov.in or nseindia.com.

4. Order-per-second limit
SEBI sets a ceiling on orders per second per algo client through the broker API.
Limit: unverified. Circular: unverified. Source: sebi.gov.in or nseindia.com.

5. Four free fixed-IP options
The trader can send orders from one fixed IP with no recurring charge. All prices and terms are unverified.
1. AWS EC2 Free Tier — small VM. Elastic IP is free if it is attached to a running instance. https://aws.amazon.com/ec2/pricing/ (unverified)
2. Oracle Cloud Free Tier — Ampere A1 VM with a public IP. https://www.oracle.com/cloud/free/ (unverified)
3. Google Cloud Free Tier — e2-micro VM in eligible regions. Static IP reservation may cost extra. https://cloud.google.com/free (unverified)
4. Azure Free Account — B1s VM with a static public IP inside the free allowance. https://azure.microsoft.com/en-in/pricing/ (unverified)
