**1. k6 (Grafana) – licence, GitHub‑Actions install, test command, failure thresholds**  
- **Licence** – MIT License, see `k6` repo `LICENSE` file 【https://github.com/grafana/k6/blob/master/LICENSE】 *UNVERIFIED*  
- **Install in a GitHub Actions workflow** – typical step:  

  ```yaml
  - name: Install k6
    run: |
      curl -s https://raw.githubusercontent.com/k6io/k6/master/install.sh | bash
  ```  

  (official install script referenced in k6 docs) 【https://k6.io/docs/getting-started/installation】 *UNVERIFIED*  
- **Run 50 parallel users for 60 seconds** – a minimal script (`script.js`) with `options = { vus: 50, duration: '60s' };` and then `k6 run script.js` 【https://k6.io/docs/using-k6/options】 *UNVERIFIED*  
- **Fail the job on p95 latency > 200 ms or error rate > 1 %** – add a `thresholds` block, e.g.:  

  ```js
  export let options = {
    vus: 50,
    duration: '60s',
    thresholds: {
      'http_req_duration{p95}': ['p(95)<200'],
      'http_req_failed': ['rate<0.01'],
    },
  };
  ```  

  When thresholds are breached k6 exits with a non‑zero code, causing the Action to fail 【https://k6.io/docs/using-k6/thresholds】 *UNVERIFIED*

**2. autocannon – licence, GitHub‑Actions install, test command, failure thresholds**  
- **Licence** – MIT License, see `autocannon` repo `LICENSE` file 【https://github.com/mcollina/autocannon/blob/master/LICENSE】 *UNVERIFIED*  
- **Install in a GitHub Actions workflow** – npm install step:  

  ```yaml
  - name: Install autocannon
    run: npm install -g autocannon
  ```  

  (npm package page) 【https://www.npmjs.com/package/autocannon】 *UNVERIFIED*  
- **Run 50 parallel users for 60 seconds** – command example:  

  ```bash
  autocannon -c 50 -d 60 https://<preview‑url>
  ```  

  (`-c` = connections, `-d` = duration) 【https://github.com/mcollina/autocannon#usage】 *UNVERIFIED*  
- **Fail the job on p95 latency or error rate** – autocannon can output JSON (`--json`) and a small wrapper can `jq` the result; exit non‑zero if `p95 > 200` or `errors > 0`. Autocannon itself does not have built‑in thresholds, so a custom step is required 【https://github.com/mcollina/autocannon#json-output】 *UNVERIFIED*

**3. OWASP ZAP (baseline scan) – licence, GitHub‑Actions install, test command, failure thresholds**  
- **Licence** – Apache 2.0 License, see `ZAP` repo `LICENSE` file 【https://github.com/zaproxy/zap-core-java/blob/master/LICENSE】 *UNVERIFIED*  
- **Install in a GitHub Actions workflow** – use the official Docker image or the `zap-cli` wrapper; a common step:  

  ```yaml
  - name: Pull OWASP ZAP Docker image
    run: docker pull owasp/zap2docker-stable
  ```  

  (Docker Hub page) 【https://hub.docker.com/r/owasp/zap2docker-stable】 *UNVERIFIED*  
- **Run 50 parallel users for 60 seconds (baseline scan)** – ZAP’s baseline scan is not a load‑test tool; to approximate concurrency you can launch the scan with `-c 50` using the `zap-baseline.py` script (the `-c` flag sets the number of concurrent threads) 【https://github.com/zaproxy/zap-baseline-scan#usage】 *UNVERIFIED*  
- **Fail the job on p95 latency or error rate** – ZAP reports alerts; a custom script can parse the generated `report.html`/`report.json` and exit non‑zero if any alert of severity “High/Medium” appears or if the average response time exceeds a threshold. ZAP does not expose p95 directly, so a wrapper is required 【https://www.zaproxy.org/docs/desktop/start/】 *UNVERIFIED*
