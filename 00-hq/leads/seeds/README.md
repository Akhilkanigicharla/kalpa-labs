# Seed lists (starter, for Akhil to review)
One organisation per line: `Name|https://their-own-site`. Only organisations' own websites. Never Google Maps, Justdial,
Instagram, Facebook, LinkedIn or IndiaMART pages, and never a person's personal number or profile.
`kalpa_leads.py` reads `seeds/<world>.txt` automatically (added to the OpenStreetMap results where a world has them).
Edit freely: add, delete, or replace with organisations you meet.
