## A341 · Understand Anything vs graft (27 Nov 2026, cloud only)

**Verdict: not kept. graft stays the first code lookup.** Understand Anything (UA) is a good onboarding map, but its first run spends far more Claude tokens than graft saves.

| Question (K178 plan) | graft 0.10.1 (live run today) | Understand Anything v2.9.8 (repo read today) |
|---|---|---|
| Cost to set up on this repo | `graft build`: 624 code files indexed, 0 LLM tokens | `/understand` sends every file to file-analyzer subagents (SKILL.md Phase 2). Our repo: 2,800 files, ~5.8 MB of code (~1.5M tokens to read once) + ~7 MB of docs. README: "can consume a significant number of tokens on large projects". Estimate ≥1.5M Claude tokens; not run for that reason |
| Find a code symbol (`deploy_budget`) | 3 hits / 2 files, ~111 tokens shown (93% saved) | needs the graph first |
| Find a version string (`0.10.1`) | 1 hit, ~62 tokens | needs the graph first |
| Find a phrase in notes (`Understand Anything`, `token-savers`) | no hits: graft indexes code only, not .md | would cover docs (it has a knowledge/wiki mode) |
| Broad search (`rate limit`) | 15 hits / 13 files, ~632 tokens (98% saved) | graph search + guided tours, after the first run |

Facts checked: licence MIT (LICENSE file, Copyright 2026 Yuxiang Lin + Infinite Universe, Inc.), last commit b232f35 on 25 Nov 2026, Claude Code plugin with 9 skills and 12 agent prompts, deterministic tree-sitter scan + LLM summaries, read-only local dashboard with no LLM once a graph exists.
