# BotBhai replies in 5 languages: review sheet (A73)

Written by Claude on 22–24 Oct 2026. **A Telugu speaker (and a Hindi speaker) must read every line before any salon goes live.** Write better wording in the Notes column and send it to Claude, or edit `core/engine.js` (bot replies) and `setups/<setup>/bot.config.js` (`i18n`).

How the bot picks: Telugu or Hindi script → that script; Tenglish words (kavali, repu, entha, cheyyandi…) → Tenglish; Hinglish words (chahiye, kitna, hai, kal…) → Hinglish; plain English → English. Typing telugu / hindi / tenglish / hinglish / english switches. Commands in *stars* (menu, cancel, book, OFFERS, STOP, START, YES, human, bot) stay in English on purpose: customers type them back.
