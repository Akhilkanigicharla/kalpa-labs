Moving from Session Buddy

Bring your Session Buddy collections into Tab Lifeboat. Nothing is uploaded: the move happens on your computer.

1. Export from Session Buddy

  1. Open Session Buddy, click the gear icon and choose Export…
  2. Choose all collections (or only the ones you want), pick JSON as the format, then click Select destination and save the file.

2. Import into Tab Lifeboat

  1. Install Tab Lifeboat from the Chrome Web Store (free).
  2. Right-click the Tab Lifeboat icon and choose Options, then find Move in from OneTab or Session Buddy.
  3. Choose the saved JSON file (or paste its text). Tab Lifeboat shows how many tabs and groups it found before you import.
  4. Click Import. Each collection or folder becomes a saved group.

Good to know

  • Both older Session Buddy files (sessions and windows) and newer ones (collections, folders and links) work.
  • Keep your Session Buddy file until you have checked the import.
  • From now on Tab Lifeboat takes automatic snapshots, and you can download a backup file any time.
