Automatic snapshots

Every 5 minutes Tab Lifeboat quietly copies all open windows, tabs and tab groups. Nothing is closed.

  • Free: keeps the last 3 snapshots.
  • Pro: keeps 90 days of history, so you can go back to any day.

Restoring

Off: Restore skips pages that are already open, so nothing opens twice.

Quick save

Right-click the Tab Lifeboat icon to save all tabs, this window, or the tabs you selected. Keyboard shortcut: Alt+Shift+Y.

Backup file

One file with every saved session. Keep it in Drive, email it to yourself, or copy it to a new computer.

Export as text

Markdown for notes apps (Obsidian, Notion), a plain list of links (OneTab format), or CSV for Excel and Google Sheets.

Move in from another tab saver

OneTab, Session Buddy, Toby (JSON), Pocket (CSV or HTML), Edge Collections (CSV, or Favorites exported as HTML) and any browser's bookmarks file. Each bookmarks folder becomes a session. You see the count before anything is saved.
