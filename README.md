# Kalpa Labs

A one-person company in Hyderabad, built with Claude, one hour a day. One parent company (the Citadel) and seven business worlds:

| Folder | World | What gets built |
|---|---|---|
| `00-hq` | 🏰 The Citadel | Company website, shared tools |
| `01-studio` | 🤖 Botforge | WhatsApp bots and sites for local businesses |
| `02-jobcard` | 🛠️ Workshop Valley | Voice job-card app for technicians |
| `03-kits` | 📚 Library of Ranks | Sheets kits for exams and money |
| `04-extensions` | 🧩 Plugin Isles | A freemium Chrome extension |
| `05-deals` | 🛍️ Bazaar Bay | Calculators, deals bot, newsletter |
| `06-finops` | 📊 Ledger Peaks | AI FinOps & Governance (flagship) |
| `07-trading` | 🔮 The Market Maze | Backtesting lab (paper only) |

## Rules

- **Build mode:** free tiers only, no paid sign-ups until we go public.
- **Nothing heavy on a local PC:** code runs in GitHub Codespaces, Google Colab, Supabase, Netlify or Cloudflare.
- **No secrets in this repo:** API keys go in GitHub/Supabase secrets, passwords in Bitwarden.
- **Every product gets its own brand name**, trademark-checked before launch.
- `archive/` holds files from this repo's earlier life.
